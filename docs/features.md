# Feature List

This is a document containing a list of features that we want to include in notus.
The goal is to get a shape of what we are working with to move quicker with development.

- Write on a page.
- Organize pages into books.
- Organize pages and books in folders.
- Name pages.
- Name books.
- Name folders.
- Open a page to write in.
- Open a book to write in.
- Flip through a book by swiping left/right.
- Change the background colour of a page.
- Change the background spacing of a page.
- Change the background pattern of a page.
- Use a pen to draw on page.
- Allow the pen to have multiple different colours.
- Allow the pen to have multiple thicknesses.
- Use an eraser to erase parts of the page.
- Configure the eraser to erase strokes or pixels.
- Gesture to undo last action.
- Export page to PDF.
- Export book to PDF.
- Delete page.
- Delete book.
- Delete folder.
- Link from one page to another page.
- Shortcut to go back from a link (could be same as undo last action).
- View book pages at high level.
- Change default background style (colour, spacing, pattern) for all new pages.
